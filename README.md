# Asha Kandula — Professional Portfolio

Responsive single-page portfolio for Asha Kandula, Microsoft Power Platform Developer.

## Files
- `index.html` — portfolio structure and content
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and active section state

## GitHub Pages
1. Create a public repository named `ashakandula.github.io`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch → main → /(root)** and save.
5. Open `https://ashakandula.github.io/` after GitHub Pages finishes deploying.
