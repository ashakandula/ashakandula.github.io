# Asha Kandula — Professional Portfolio

A responsive single-page portfolio website for Asha Kandula, Microsoft Power Platform Developer.

## Files
- `index.html` — portfolio structure and content
- `styles.css` — responsive visual design
- `script.js` — mobile navigation

## Publish with GitHub Pages
1. Create a public repository named `ashakandula.github.io`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

Portfolio URL: `https://ashakandula.github.io/`
