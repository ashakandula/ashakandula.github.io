# Asha Kandula — Professional Portfolio

A responsive single-page portfolio website for a Microsoft Power Platform Developer.

## Files
- `index.html` — main website
- `styles.css` — responsive visual design
- `script.js` — mobile navigation

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `asha-portfolio`.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. In GitHub: Settings → Pages → Deploy from branch → select `main` and `/root`.
4. GitHub will provide the public portfolio URL.

## Personalize
- Replace the LinkedIn URL if needed.
- Update the email/phone if your preferred contact details change.
- Add screenshots to project cards later if you want a more visual case-study version.
